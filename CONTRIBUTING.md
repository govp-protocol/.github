# Contributing to GOVP

Use [`govp-protocol/govp`](https://github.com/govp-protocol/govp) for changes
to the specification, signed bytes, identifiers, schemas, conformance vectors
or reference verifier.

Use [`govp-protocol/govp.io`](https://github.com/govp-protocol/govp.io) for
website, accessibility and rendered-documentation changes. Normative copies in
the website repository must remain byte-identical to the approved protocol
source.

Do not submit secrets, customer data, personal records, private evidence or
real signing keys. Security reports follow [`SECURITY.md`](SECURITY.md).
